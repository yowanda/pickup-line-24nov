A deterministic Python program (stdlib only, no network) that writes the line to `entry.txt`, capped at 200 characters, warm rather than creepy, with the charm landing at the end.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/pickup-line-out python3 main.py
```
